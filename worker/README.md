# MatchPilot Browser Worker

常時起動したChromeプロファイルを使い、管理画面から受け取ったジョブを実行するゼロ依存のNode.jsワーカーです。

## 初期設定

1. `.env.example` を `.env` にコピーする。
2. `CONTROL_PLANE_URL`、`WORKER_SHARED_SECRET`、`WORKER_BINDING_TOKEN`、`WORKER_USER_ID` を管理画面の値に合わせる。ユーザー専用トークンは再表示されないため安全に保管する。
3. `CHROME_EXECUTABLE_PATH` をChromeの実行ファイルへ設定する。
4. PowerShellで `./start-worker.ps1` を実行する。
5. Chromeが開いたら、接続対象サービスのログイン・認証・本人確認を手動で完了する。
6. `./doctor.ps1` を実行し、常駐設定と本番接続を確認する。

Node.js 22以降が必要です。常時運転する場合は、手動起動で動作確認した後に `./install-autostart.ps1` を一度実行してください。Windowsログオン時に起動し、Node停止時は10秒後、タスクごと停止した場合も1分以内に自動復旧します。ログは `worker/data/worker.log` に追記されます。解除は `./install-autostart.ps1 -Uninstall` です。

文章生成用APIキーはワーカーにだけ保存され、コントロールプレーンへ送信されません。未設定でもワーカーは監視・接続準備を継続し、管理画面へ`degraded`として理由を表示します。管理画面の返信編集・承認履歴はD1に残り、直近の会話と承認済み文体例だけが次回生成時にワーカーへ渡されます。

パスワード、Cookie、認証コードは管理画面へ送信せず、`WORKER_DATA_DIR` のChromeプロファイルだけに保存されます。このディレクトリはバックアップや共有の対象にしないでください。

## 安全仕様

- CAPTCHA、認証コード、本人確認、決済を自動突破しません。
- HTTPSかつ接続対象サービスの許可ホスト以外へ遷移しません。
- いいね・送信ボタンが画面上で一意に特定できない場合は操作を中断します。
- ワーカーIDはユーザー専用トークンで所有者へ固定され、別ユーザーの情報やジョブを要求できません。
- ジョブはワーカーID付きでリースされ、期限切れ時だけ別の処理へ戻ります。
- 送信・いいねの完了直後にローカルジャーナルへ記録し、結果報告時の通信断でも同じ操作を繰り返しません。
- 全体停止中、接続が確認待ち・停止中・期限切れのサービスは自動巡回しません。
- 毎日 `SUMMARY_HOUR`（日本時間、初期値21時）以降に1回だけTelegramサマリーを送ります。
- Chromeをヘッドレスにすると手動認証できないため、初期設定では `HEADLESS=false` を推奨します。

## 対応状態

- 公開Web入口: 31件。ログイン画面を安全に開くためのHTTPS許可リストであり、外部自動操作の許可を意味しません。
- 自動巡回・いいね・送信は、サービス提供者の明示的な許可が確認できた接続だけ実行します。現時点の標準設定では全接続を停止し、公式機能または手動操作へ案内します。
- with、Omiai、marrishは公式規約で自動投稿・クローリング等の禁止を確認済みのため、外部自動操作を常時ブロックします。Pairsを含む許可未確認サービスも同様に実行しません。
- 対象外: Tinder（無許可の自動アクセス・第三者AI連携を規約で禁止）、tapple（ブラウザ版がアカウント管理のみ）、D³ / Dine（操作可能な会員向けWeb版を公式確認できない）
- DOM抽出はサービス側UI変更の影響を受けます。一意に安全確認できないボタンは押さず、エラーとして停止します。
- 規約確認だけでなく、サービス提供者からの明示的な許可または公式APIが必要です。
